# TabCloser（浮动按钮关闭标签页 · Chrome 扩展）

在页面顶部中央添加一个**小尺寸浮动按钮**（默认贴边隐藏，悬停弹出），点击即可关闭当前标签页。

## 功能

- 按钮默认贴边隐藏在页面顶部中央（36px 圆形，半隐藏只露出一小半，始终保持纯圆形）
- **悬停**按钮 → 滑出显示；**点击**按钮 → 关闭当前标签页
- **拖动**按钮 → 移动到页面任意位置，不会触发关闭；位置自动保存（本机记忆）
- **贴边隐藏**：拖到屏幕上 / 左 / 右边缘时按钮自动吸附并半隐藏，鼠标悬停时滑出，点击照常关闭
- **隐形热区**：贴边隐藏时按钮周围（向屏幕内侧）有 20px 的隐形触发范围，悬停弹出、点击关闭都更容易命中，不必精确瞄准露出的小弧线
- **重置位置**：设置页提供一键重置，所有网页的按钮立即回到页面顶部中央贴边隐藏
- 窗口尺寸变化时按钮自动保持在可视区内（未自定义过位置时保持顶部居中；右侧有滚动条时自动避开）
- 按钮使用 Shadow DOM + 最高 z-index，不受页面样式影响、不被遮挡
- 悬停效果不使用 scale 变换，避免部分页面首次悬停时的整页重绘抖动
- 连续关闭 / 切换标签页时（页面从后台切回前台、鼠标正停在按钮上），弹出动画照常播放，不会"瞬间出现"
- 仅在顶层页面注入，iframe 中不会出现重复按钮
- 点击工具栏图标可随时开关按钮显示，修改后无需刷新页面

## 安装方式（开发者模式加载）

1. 打开 Chrome，地址栏输入 `chrome://extensions/` 回车
2. 打开右上角的 **开发者模式** 开关
3. 点击左上角 **加载已解压的扩展程序**
4. 选择本文件夹（`double-click-close-tab`）
5. 安装完成，打开任意网页即可看到右下角的浮动按钮

## 文件结构

```
double-click-close-tab/
├── manifest.json    # 扩展清单（Manifest V3）
├── background.js    # Service Worker：执行关闭标签页操作
├── content.js       # 内容脚本：注入浮动按钮（Shadow DOM 隔离）
├── options.html     # 设置页（点击工具栏图标弹出）
├── options.js       # 设置页逻辑
└── icons/           # 图标（16/48/128）
```

## 权限说明

- `tabs`：用于关闭标签页
- `storage`：保存开关设置（sync）与按钮位置（local）
- 内容脚本注入所有网页：用于显示浮动按钮
